Optimistic execution, one gate at a time.

TapeOut circuits are NAND gates with exact, public semantics, stored on-chain and never changed. That makes every single step of any circuit checkable by a contract.

  1. 01

    Post a job

    Name any taped-out circuit, give it a starting state, choose how many beats to run, and attach a fee.

  2. 02

    Claim with a bond

    An operator runs it off-chain and posts the result with a Merkle root over every wire value.

  3. 03

    Anyone can challenge

    A watcher re-runs the job for free. If the roots differ, the two sides halve the trace until one gate is left.

  4. 04

    The contract checks one step

    It recomputes that single NAND, LATCH or REF wire from the circuit's on-chain netlist. The liar loses the bond.

Post or work a job yourself

Anyone can post a job, run an operator that claims jobs for fees, or run a watcher that challenges wrong claims for bonds. From a checkout of the repository:

export RPC_URL=https://rpc.xlayer.tech PRIVATE_KEY=0x…
node bin/overclock.js post --cpu 0xb00f10bb4b2f32c561bf90e205e543d0a2395971 --id 5 --beats 40 --fee 0.0002
node bin/overclock.js operator   # claim open jobs, defend the claims
node bin/overclock.js watch      # re-run every claim, challenge wrong ones

AI agents get the same actions as MCP tools through the Claude Code plugin in the repository.

TapeOut setup
