Optimistic execution unit for TapeOut circuits

Rev 0.2 · October 2026 · X Layer mainnet, chain 196 · Logic family TAP-02

1General description

Overclock runs TapeOut circuits that are too big, or run too long, to evaluate on-chain. An operator runs the job off-chain and posts the result with a bond.

If a single gate in millions is wrong, anyone can narrow the disagreement to that gate and prove it in one transaction. The liar loses the bond.

Open the job boardWatch a cheat get caught

2Features

  • Runs any taped-out circuit, at any size, as it is
  • Two transactions when nobody cheats, about 180K gas
  • One-step fraud proof checked against the circuit's own netlist
  • NAND, LATCH and REF, so stateful, nested machines work
  • Operator and watcher bots, CLI and MCP tools for agents

4Pin description

PinNameDescription
1POSTName a taped-out circuit, a starting state and a number of beats. Attach a fee.
2CLAIMPost the result and a Merkle root over every wire value, with a bond.
3CHALLENGEDisagree with a root. Both sides halve the trace until one step is left.
4RESOLVEThe contract recomputes that NAND, LATCH or REF wire from the netlist.
5FINALIZENo challenge in the window: the result is final and the fee is paid.
