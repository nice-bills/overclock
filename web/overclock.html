03Typical application

Nobody pays to check a result unless someone disagrees.

A TapeOut circuit is NAND and LATCH transistors burned into a netlist that lives on-chain and never changes. So any single gate of any circuit, at any size, is a step a contract can re-check.

1POST

Name any taped-out circuit, a starting state and a number of beats. Attach a fee.

2CLAIM

An operator runs it off-chain and posts the result with a Merkle root over every wire value, plus a bond.

3CHALLENGE

A watcher re-runs it for free. If the roots differ, both sides halve the trace until one step is left.

4RESOLVE

The contract recomputes that NAND, LATCH or REF wire from the circuit's on-chain netlist. The liar loses the bond.

5FINALIZE

Nobody challenged in the window: the result is final and the operator is paid.

Post or work a job yourself

Anyone can post a job, run an operator that claims jobs for fees, or run a watcher that challenges wrong claims for bonds. From a checkout of the repository:

export RPC_URL=https://rpc.xlayer.tech PRIVATE_KEY=0x…
node bin/overclock.js post --cpu 0xb00f10bb4b2f32c561bf90e205e543d0a2395971 --id 5 --beats 40 --fee 0.0002
node bin/overclock.js operator   # claim open jobs, defend the claims
node bin/overclock.js watch      # re-run every claim, challenge wrong ones

AI agents get the same actions as MCP tools through the Claude Code plugin in the repository.
